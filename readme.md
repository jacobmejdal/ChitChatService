How to run the program:

1. Open a terminal, and go to path /ChitChatService
2. Run the server via this command line: go run server/server.go
3. Open a new terminal and run this command line to connect a new client to the chat: go run client/client.go
4. Then type in the name of the new client
5. Repeat step 3 and 4 for as many times as you want
6. When done, disconnect the clients, in their terminal, by typing: /leave
7. Shut the chat down by pressing ctrl + c or command + c, in the server terminal
